First-Year Computer Science Programming Project

A Demo project about e-commerce and shopping mall desktop GUI simulation application developed with Python and SQLite.

About this project :

- Shopping Mall XD is a desktop application simulating an online shopping mall system. It was developed to study and apply fundamental concepts of structured/functional programming, Graphical User Interface (GUI) design, and relational database integration.

The program handles the end-to-end shopping workflow—from user authentication and product browsing to automated checkout calculations, reward point accumulation, and transaction history tracking.

Key Features :
1. Member System
  - Reward Points: Automatically awards points upon completing purchases, updating member records in real time.
2. Store & Promotions
  - Storefront: Displays available products complete with images and pricing.
  - Promotions: Features discounted items and bonus point incentives.
  - Automated Checkout: Allows quantity selection via spinboxes and calculates the order total prior to confirmation.
3. Order History
  - Displays past purchases filtered by the logged-in user.
  - Presents transaction logs in structured tables using ttk.Treeview.
  - Calculates cumulative lifetime spending across all completed orders.

4. User Experience
  - Light / Dark Mode: Supports dynamic theme switching between light and dark UI themes.
  - Dialogs & Notifications: Provides interactive popups for action confirmations, errors, and system warnings.
